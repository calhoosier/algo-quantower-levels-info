IVD Watch Publisher

IVD Watch Publisher is a personal monitoring utility operated by Amish Patel. It uploads run-status reports and sanitized diagnostic logs from a local IVD Watch installation to the owner's private Google Drive.

Google Drive access

The utility requests the drive.file permission to create and update monitoring files it creates or that the owner explicitly authorizes for use with the app. It does not request access to the entire Drive.

Background authorization allows scheduled uploads without requiring interactive sign-in for every run. Monitoring files are not published by this website.

This utility is for the owner's personal use and is not offered as a public service.
